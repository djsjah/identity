# I-Dentity

**Тема:** Разработка когнитивной системы поддержки решений для верификации цифровых изображений и обнаружения deepfake-контента.

- Ноздряков Богдан — M4206

## Описание проекта

I-Dentity — система поддержки принятия решений, предназначенная для проверки цифровых изображений на наличие признаков подмены лица (deepfake). Система принимает изображения, анализирует их с помощью машинного обучения и на основе полученной оценки и заданных правил формирует рекомендацию по дальнейшему действию.
